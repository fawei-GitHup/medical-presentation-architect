# Contributing

请用 issue/PR 描述问题、受众影响、复现输入与预期结果。仅提交合成或获得明确再分发许可的样本，不上传患者数据、密钥、内部 SOP 或他人原稿。
核心规则在根 SKILL.md / rules / workflows；适配层只维护宿主差异；skills/ 是 package.py 生成的发布副本，禁止手工修改。schema 变更应兼容旧项目或说明迁移。
修改脚本需添加有意义的正反测试：无证据、陈旧审核、路径穿越、安装冲突、渲染失败不得通过。运行 release_check、unittest 和 ruff。视觉更改需真实回渲染并查看全部页面，临床规则更改需领域审阅与可核验来源。
提交意味着你有权提交相关内容，并同意项目所有者可按仓库当前许可证以及另行提供的商业许可证分发该贡献。第三方内容必须单独登记；不得把患者材料、他人模板、论文图片或付费素材作为自己的贡献提交。
