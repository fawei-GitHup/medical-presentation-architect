# 本地中文 Web 工作台

`ui/` 是 Medical Presentation Architect 的零构建依赖前端。它用于完成需求访谈、页面架构、视觉类型选择、证据登记与项目导出。界面不引用外部 CDN；只有在用户点击“创建本地项目”后，才会把配置和已选择的材料发送到同源本地服务，不会发送到互联网。

## 本地预览

直接双击 `index.html` 即可使用。为了获得与后续本地服务相同的运行方式，也可以在仓库根目录启动静态服务器：

```bash
python -m http.server 8765 -d ui
```

然后打开 `http://127.0.0.1:8765`。

## 数据处理

- 表单、页面计划与证据项自动保存到浏览器 `localStorage`。
- 文件选择器在静态模式下只记录文件名、大小和类型。连接同源本地服务并点击“创建本地项目”后，所选文件会逐个写入本机项目目录。
- “下载项目配置”输出 `medical-presentation-project.json`。
- “下载执行提示词”输出 `execution-prompt.md`，可交给 Kimi CLI 或后续本地 Python 服务。
- “清空本地项目”会先要求确认，然后删除该页面保存的浏览器数据。

## 与本地服务集成

前端通过 `GET /api/health` 检查同源本地服务，通过 `POST /api/projects` 创建项目，再把用户选择的文件逐个发送到 `POST /api/projects/{name}/files`。本地服务返回的 Kimi CLI 命令会显示在生成页。服务应只监听 `127.0.0.1`，对路径做白名单校验，并保持病例文件在项目目录内。

## 浏览器支持

支持近期版本的 Chrome、Edge、Firefox 和 Safari。界面提供键盘焦点、语义标签、减少动效适配和响应式布局。
