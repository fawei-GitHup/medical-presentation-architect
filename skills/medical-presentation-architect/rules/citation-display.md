# citation-display

`sources.json` 中的 `SRC1`、`SRC2` 等是机器账本 ID，不是面向听众的引文。正文页脚、图注和表格来源必须显示可读短引文（如 `Sannino et al., 2015`），或使用稳定的正式编号；若使用编号，参考文献页必须逐条、一一对应地给出完整书目信息。内部 ID、URL、DOI、定位段落和核实状态可保留在 speaker notes 与证据账本中。

构建后运行 `source-map-check`。它必须检查正文中的内部 ID 泄漏、页面/notes 使用的 ID 是否存在、末尾参考文献或附录是否有完整映射，以及映射的遗漏、重复和顺序。该检查只验证引用展示与引用关系，不证明来源支持医学结论。

可读性优先于把所有来源挤进单页：一页引用过多时缩短到作者—年份并把完整条目拆到多页附录，不能缩小到无法投影阅读。
