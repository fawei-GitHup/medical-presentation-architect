# 演示语言与术语

遵循当前 brief 中的 `language`；未明确其他偏好时默认中文优先。流程、叙述、标题、表格说明、图表轴/图例、步骤标签、风险提示、notes 和讲者提问尽可能用清楚的中文表达。

保留设备/耗材型号、产品名、厂商名、指南/标准正式名称和不可替代的专有名词原文。首次出现时，可采用“规范中文名（English term, acronym）”；同一 deck 后续使用一致的中文名/缩写。若没有可靠中文译名，保留原文并用短中文解释，不自行创造官方译名。

中英双语只在用户提出、受众需要或文献/设备术语易混淆时采用。采用双语时优先“中文主标签 + 英文原词/缩写”，避免所有段落机械重复翻译、挤压字号或干扰图表层级。参考文献题名保持原始书目信息，另按格式要求添加中文说明。
