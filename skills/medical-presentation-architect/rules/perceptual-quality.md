# perceptual-quality

JSON 计划通过不代表最终 PPTX 视觉合格。构建后运行 PPTX 级 `perceptual-preflight`，渲染后再次运行并结合 contact sheet 与逐页 PNG 人工确认。

重点检查：孤字/孤行、文本框和整页密度、参考文献字号、大面积低信息卡片、同页卡片数量、连续页面同构、页面越界、元素间距、过小图片、流程节点相交、connector 缺失及被节点遮挡。每条 finding 必须记录 `slide_id`、shape、可复核证据与修复建议；启发式 warning 需在渲染图中确认，不能静默忽略。

流程图按可用泳道宽度统一计算节点宽度和 gap。connector 先绘制、节点后绘制，并以节点边界为端点；节点之间保留可见间隙。禁止用手填坐标累积来模拟均分。

机器检查不评判医学真实性、隐私授权或美学完成度。出现误报时在审核记录中写明页面证据与保留理由，而不是关闭整类检查。
