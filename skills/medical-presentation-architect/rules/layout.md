# layout

默认 16:9，外边距 0.45–0.6 英寸，标题 30–36pt，正文 20–26pt，图注与出处通常 11–14pt。投影场景不以小字塞满。中文用 Microsoft YaHei/Noto Sans CJK SC 等已安装字体，字体缺失先解决或明确记录替换。
内容区避开标题和页脚；对齐使用稳定网格，组内间距小于组间。推荐保留 15–25% 空白但不机械计数。减少长段落，以图解关系；详细内容进 notes/附录。色彩对比、色盲友好、图表直接标注、单位清楚；不能仅靠颜色传递风险。
自动边界、字号、图片 PPI、文本容量估计只是筛查；复杂字体、表格、裁切、蒙版、组对象须回渲染检查。显式 intentional_overlap 只表示需复核，不能掩盖遮挡。
