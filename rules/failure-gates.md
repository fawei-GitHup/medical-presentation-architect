# failure-gates

最终导出硬门禁：intake 不全/冲突未解决；JSON 或 ID 关系错误；关键主张缺来源、未审核、来源已撤稿或无法验证；图像来源/许可/临床隐私未通过；草稿越界/严重遮挡/文字溢出/模糊；缺渲染图或逐页审核；审核绑定哈希失效；讲稿或页数不满足项目要求。
工程命令只在 final export 创建 final/deck.pptx，build 只生成 draft。任何语义/素材/PPTX/渲染变更使已有 review 失效。qa 每次重新计算；失败返回非零并写报告。
布局重复、重复图片、文字密度等启发式先列 warning，由逐项 warning_resolutions 解释或修改；不得一键忽略全部。医疗真实性和隐私的硬失败不能用 warning resolution 覆盖。
人工复核是明确的信任边界：review.json 是有姓名/角色/时间的可审计记录，不是数字签名，也无法阻止有写权限的人伪造。脚本不认证医生资格、不保证视觉零缺陷。临床部署由机构负责人确认。
